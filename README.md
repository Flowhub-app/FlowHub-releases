# FlowHub Desktop — релизы

Готовые установщики FlowHub Desktop для Windows и канал автообновления.

- **Скачать последнюю версию:** [Releases → последний релиз](https://github.com/Flowhub-app/FlowHub-releases/releases/latest) → `FlowHub-x.y.z-setup.exe`.
- **Обновления:** установленный FlowHub сам проверяет этот репозиторий — при запуске и каждые 4 часа. Обновление скачивается в фоне и ставится при выходе из программы или по кнопке «Перезапустить и обновить».
